VoiceKit Help

Voice input for macOS — one global hotkey, speak and it's typed

中文

Getting Started

  1. On first launch, grant three permissions when prompted: Microphone, Speech Recognition, and Accessibility (used to simulate pasting). All under System Settings → Privacy & Security.
  2. In any app, press the hotkey to start speaking, press again to stop — the text is pasted right where your cursor is.
  3. View or change the hotkey in Settings → General. Click the VoiceKit icon in the menu bar anytime to switch engines or browse history.

Speech Engines

Four engines are available — switch in the menu bar panel or Settings → Speech Engine:

  • System Dictation: built into macOS, free, works out of the box.
  • Aliyun Fun-ASR: high accuracy with automatic punctuation, great for long dictation; requires an Aliyun Bailian API Key and Workspace ID.
  • iFLYTEK / Deepgram: require credentials from their respective platforms.

If the selected engine has no credentials configured, recording falls back to System Dictation instead of failing.

AI Polish

When enabled, transcripts are polished by an LLM before pasting: filler words removed, grammar fixed — speech becomes clean writing.

Configure a Model

Add models in Settings → AI Service / Model Management. Two kinds are supported:

  • OpenAI-compatible API: any service with a compatible /chat/completions endpoint (OpenAI, DeepSeek, Qwen, etc.).
  • Ollama local models: fully offline, data never leaves your Mac.

Prompts

The prompt drives the polish result. In Settings → Prompt Management you can:

  • Edit the Default prompt, or create your own templates;
  • Import ready-made templates from the built-in preset library (key points, formal documents, business English, and more) — imported copies are yours to modify;
  • Use "Test Polish" to try a sample before saving.

While recording, the panel shows the active prompt's name; you can also switch model and prompt directly from the menu bar panel.

History, Favorites & Snapshots

  • History: every transcript is saved automatically (limit adjustable in Settings → History & Data), with search, copy, re-insert, and export.
  • Favorites: star frequently used items to keep them together.
  • Snapshots: save selected history items as long-lived snippets — perfect for templates and canned replies.

Quick Insert Panel

A keyboard-first floating panel for fast insertion (hotkey configurable in Settings → General):

  • ⇥ Tab switches between Snapshots / Favorites / History
  • ↑↓ to select, ↵ to insert into the target app
  • Just type to search, esc to close

Data & Configuration

  • Everything stays on your Mac in ~/Library/Application Support/VoiceMate/ — nothing passes through third-party servers.
  • The config is backed up automatically before every save (config.backup.json). If the config is ever corrupted, VoiceKit restores from the backup; failing that, it isolates the bad file and tells you — no crash.
  • Settings → History & Data supports exporting / importing the config, making migration to a new Mac easy.

FAQ

Q: The hotkey doesn't work?
A: Make sure VoiceKit is granted under System Settings → Privacy & Security → Accessibility. Right after granting, restart VoiceKit once — macOS caches the old permission state.

Q: Nothing happens when I press the hotkey?
A: Check the Microphone and Speech Recognition permissions. For Aliyun, also verify the API Key, Workspace ID, and network.

Q: Text got pasted twice in some app (e.g. Chrome)?
A: Quit and reopen that app. It's a transient state issue in the target app's accessibility interface — your text wasn't recorded twice.

Q: AI Polish won't connect?
A: For cloud models, check the Base URL and API Key. For Ollama, make sure the local service is running (ollama serve) and the model is pulled.

Q: Can I change the UI language or text size?
A: Yes. Settings → General lets you pick a language (follow system, or one of 10 languages) and adjust text size.
