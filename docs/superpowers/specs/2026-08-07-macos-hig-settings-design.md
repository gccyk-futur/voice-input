# macOS HIG 设置与可读性改造设计

> 状态：已获用户授权开始实施

## 目标

把 VoiceKit 的设置窗口和关键设置相关界面改造成更符合 macOS 使用习惯的产品界面，重点解决导航层级、文字可读性、语义颜色、权限状态反馈和渠道差异说明问题。不得改变已验证的 ASR、录音、回写、历史记录和渠道签名行为。

## 用户问题

- 当前设置页使用顶部 segmented picker，随着设置项增加会显得像临时工具而不是稳定的 macOS 设置窗口。
- 重要说明使用 caption/tertiary 等较弱的文字层级，用户感觉文字偏小、颜色偏暗。
- 设置窗口和面板使用固定尺寸，文字放大或文案变长时容易拥挤。
- 权限页把必需权限、写回方式、渠道限制和重启说明混在一起。
- 官网版与 App Store 版的写回能力不同，但当前说明和状态没有动态表达。

## 设计原则

1. 默认使用 macOS 系统字体和语义文字样式；不嵌入自定义字体。
2. 使用系统语义颜色，确保浅色、深色和增加对比度模式下的可读性。
3. 关键状态同时使用文字、图标和颜色，不能依赖颜色单独传达含义。
4. 重要正文不使用 caption/tertiary 作为主要承载样式；小字号只用于元数据。
5. 设置窗口使用稳定的侧边栏/面板导航，当前面板有清晰标题，窗口可调整大小并恢复上次面板。
6. 应用内文字大小提供“跟随系统 / 较大 / 更大”三档，不提供不可控的任意滑杆。
7. 权限状态必须由真实系统状态驱动，文案与可执行动作保持一致。

## 设置窗口信息架构

```text
VoiceKit 设置
├── 常规
├── 语音输入
├── 文字写回
├── 服务
├── 权限与隐私
└── 关于
```

左侧导航使用 SF Symbols 和系统强调色；右侧面板使用标题、说明、分组行和原生控件。优先使用 SwiftUI 的 Form、Section、LabeledContent、Toggle、Picker 和 Button，减少装饰性卡片和固定颜色。

## 文字系统

建立集中式 `VoiceKitTypography` 与 `VoiceKitSemanticColor`，覆盖设置窗口、权限页、状态栏面板、录音面板和历史窗口的自定义文字。

### 文字大小

- `system`：使用系统样式和默认比例。
- `large`：自定义内容约 1.15 倍。
- `extraLarge`：自定义内容约 1.30 倍。

系统控件继续使用系统字体；自定义内容使用同一套比例环境。文字变大时必须允许换行、滚动和窗口扩大，不能裁剪说明或按钮。

### 文字层级

- 页面标题：Title 1/Title 2。
- 分组标题：Title 3/Headline。
- 主要正文：Body。
- 辅助解释：Callout/Body 的次级颜色。
- 版本号、时间和非关键元数据：Caption。

## 权限与渠道状态

### 官网版

- 麦克风、语音识别：必需权限，授权后显示“已授权，可使用”。
- 辅助功能：用于直接访问目标输入框写入文字，也可能作为热键回退能力。
- 辅助功能授权后，如果本次运行需要重新加载，显示“退出并重新打开 VoiceKit”；按钮由用户主动触发，并提供稍后处理。
- 未授权时明确说明识别仍可用，但写回会退化为剪贴板和手动 ⌘V。

### App Store 版

- 不展示辅助功能直接写入卡片。
- 展示“自动写回（键盘事件）”并说明这是沙盒版的写回路径。
- 已授权：说明“允许尝试自动写回”，不承诺目标应用一定接受。
- 未授权或自动写回失败：说明文字仍保留在剪贴板，可手动按 ⌘V。
- 说明官网版可使用直接写入能力，但不得贬低渠道版本或暗示自动写回必然成功。

公共权限状态使用“未设置 / 已拒绝 / 已授权”；状态变化在从系统设置返回后刷新。只有辅助功能等确实可能需要重新加载的权限显示重启提示，移除全局静态“授权后需要重启 App”说明。

## 非目标

- 不修改 ASR 引擎、音频预缓冲、麦克风路由、WebSocket、历史记录和回写核心实现。
- 不改变 App Store 或官网版签名、沙盒、entitlements 或权限申请策略。
- 不把所有界面强行改造成数据仪表盘；设置页优先保持原生、安静、可扫描。

## 验收标准

1. 设置窗口具备稳定的 macOS 风格导航，窗口可调整大小，面板标题和选中项一致。
2. 默认文字不再以小字号/低对比度承载关键说明；深色和增加对比度模式可读。
3. 应用内文字大小可在三档之间切换，长文案不会被裁剪。
4. 权限页能根据渠道和真实授权状态展示不同说明与动作。
5. 辅助功能授权完成后能提供明确的退出并重新打开按钮。
6. 既有 ASR、回写、历史记录和权限相关测试继续通过。
