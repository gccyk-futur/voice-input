VoiceKit 使用帮助

macOS 语音输入助手 — 全局热键，说话即输入

English

快速上手

  1. 首次启动按提示完成三项授权：麦克风、语音识别、辅助功能（用于模拟粘贴）。都在 系统设置 → 隐私与安全性 中。
  2. 在任意 App 里按下热键开始说话，再按一次结束 —— 文字会自动粘贴到当前输入位置。
  3. 热键可在 设置 → 常规 中查看和修改；点击菜单栏的 VoiceKit 图标可随时切换引擎、查看历史。

语音引擎

VoiceKit 支持四种识别引擎，在状态栏菜单或 设置 → 语音引擎 中切换：

  • 系统听写：macOS 内置，免费、无需联网配置，开箱即用。
  • 阿里云 Fun-ASR：高精度、自动标点，适合长连续口述；需配置阿里云百炼的 API Key 和 Workspace ID。
  • 讯飞听写 / Deepgram：需各自平台的凭据。

所选引擎未配置凭据时，录音会自动回退到系统听写，不会失败。

AI 润色

开启后，识别结果会先经过大模型润色再粘贴：去口头禅、修语病，让口语变书面。

配置模型

设置 → AI 服务 / 模型管理 中添加模型，支持两类：

  • OpenAI 兼容协议：任何兼容 /chat/completions 的云端服务（OpenAI、DeepSeek、通义等）。
  • Ollama 本地模型：完全离线，数据不出本机。

提示词

润色效果由提示词决定。设置 → 提示词管理 中可以：

  • 编辑「默认」提示词，或新建自己的模板；
  • 从内置预设库一键导入现成模板（要点清单、正式公文、商务英文等），导入后可自由修改；
  • 用「测试润色效果」输入一段话试跑，满意再保存。

录音时，右下角面板会显示当前生效的提示词名称；状态栏菜单里也能直接切换模型和提示词。

词汇纠正

引擎总把某个词听错？（比如把「Claude Code」识别成「cloud code」）在 设置 → 词汇纠正 中登记一条替换规则，以后的识别结果会自动纠正，对所有识别引擎生效。

  • 纠正在润色、粘贴、写入历史之前应用，后续环节拿到的都是纠正后的文本；
  • 发生改动时，历史记录会保留原始识别文本，并显示「已纠正」徽标，方便对照；
  • 规则只存在本机配置里，可随时编辑或删除。

历史、收藏与快照

  • 历史：每次转写自动保存（上限可在 设置 → 历史与数据 调整），支持搜索、复制、再次插入、导出。
  • 收藏：常用内容标星，集中查看。
  • 快照：把选中的历史条目存成长期片段，适合模板、常用回复。

语音留档与重新识别

  • 开启后（设置 → 历史与数据），每条历史可同时保存当时的录音（AAC，只存本机）；
  • 识别不理想时点「重新识别」：用该条当时所用的引擎对留档再识别一次，网络抖动不再丢字；
  • 录音随历史删除 / 清空一并清理，占用大小在 设置 → 数据隐私 中可见。

历史词云

  • 默认关闭，在 设置 → 词云 中开启；点开即算当前词云，可预览、导出 HTML / JSON；
  • 锚定快照：每累计一定字数自动切一张词频快照，留住用词随时间的变化；
  • 全部本机计算，只存词和次数，不含原文。

速插面板

键盘优先的快速插入浮层（热键在 设置 → 常规 中配置）：

  • ⇥ Tab 切换 快照 / 收藏 / 历史 标签
  • ↑↓ 选择，↵ 插入到目标 App
  • 直接打字即可搜索，esc 关闭

数据与配置

  • 所有数据只存在本机 ~/Library/Application Support/VoiceMate/，不经过任何第三方服务器。
  • 配置每次保存前自动备份（config.backup.json）；配置损坏时自动从备份恢复，恢复不了会隔离坏文件并提示，不会崩溃。
  • 设置 → 历史与数据 支持导出 / 导入配置，换机迁移很方便。
  • 设置 → 数据隐私 逐一披露每个本地数据文件的位置与大小（历史、快照、录音、词云、统计、日志），可显示所在目录、可清空。

常见问题

Q: 热键不生效？
A: 检查 系统设置 → 隐私与安全性 → 辅助功能 中 VoiceKit 已授权。刚授权完需要重启一次 VoiceKit 才能识别到新权限（系统缓存限制）。

Q: 按下热键没反应或无法识别？
A: 检查 麦克风 和 语音识别 两项权限；阿里云引擎还需确认 API Key、Workspace ID 填写正确且网络可用。

Q: 在某个 App（如 Chrome）里粘贴出现重复文字？
A: 退出该 App 重新打开即可。这是目标 App 的辅助功能接口偶发状态异常，不是文字被录了两次。

Q: AI 润色连不上？
A: 云端模型检查 Base URL 和 API Key；Ollama 确认本地服务已启动（ollama serve）且模型已拉取。

Q: 引擎总把同一个词听错？
A: 在 设置 → 词汇纠正 中加一条替换规则，以后自动纠正，对所有引擎生效；历史里可用「已纠正」徽标对照原文。

Q: 感觉「已连接但不出字」，怎么排查？
A: 开启语音留档后回放当时的录音：有声音说明是识别环节丢了，可用「重新识别」补回；没声音则是麦克风或系统层问题。

Q: 界面语言/文字大小可以调吗？
A: 可以。设置 → 常规 中切换语言（跟随系统或手动指定 10 种语言之一）和文字大小。
